# Recursos de Compilación e Iconos de la Aplicación

Coloca aquí los iconos definitivos de la aplicación:
- **`icon.icns`**: Icono oficial para macOS (soporta resoluciones desde 16x16 hasta 1024x1024 Retina).
- **`icon.ico`**: Icono oficial para Windows (256x256 multi-resolución).
- **`icon.png`**: Icono de respaldo (512x512).

`electron-builder` empaquetará automáticamente estos archivos al compilar para macOS (`npm run build:mac`) y Windows (`npm run build:win`).
